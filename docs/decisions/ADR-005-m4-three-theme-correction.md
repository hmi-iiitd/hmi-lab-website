# ADR-005 — M4 correction: three research themes (not four)

**Status:** Accepted (2026-11-04)  
**Related:** ADR-003; `docs/proposals/M4-RESEARCH-THEMES-AND-FLAGSHIPS.md` (M4.0 conditional pass)

## Context

`HMI_WEBSITE_PRD.md` §8 RES-01 and §10 M4 still describe **four** research theme pages and an older exploratory identity. The lab’s approved scientific identity (ADR-003) and the frozen staging site use **three** primary themes under Interactive Intelligence.

## Decision

For M4 and onward:

1. Ship **exactly three** research-theme detail pages:  
   `perception-understanding`, `learning-coordination`, `interaction-adaptation`.  
2. Treat PRD references to “four themes” / “four theme pages” as **superseded** by ADR-003 + this ADR.  
3. Do not revive the retired four-theme ids from ADR-003’s migration table.  
4. Theme-page publication lists use verified **public** records (`published` or `accepted`), so ESL appears under Learning & Coordination as Accepted.

## Consequences

- M4.1 implements three theme routes only.  
- PRD errata note points here.  
- Homepage copy, typography, logo, and research positioning remain frozen unless a separate substantive decision revises them.
